GWS Read-Only Automation

An internal, single-operator automation tool for Google Workspace reporting. Not a public product.

What this application does

This is a private, single-operator command-line tool. It reads Google Workspace data only for the one Google account that explicitly authorized it, and produces internal operational reports: school enrolment and attendance summaries, CRM spreadsheets, training and timetable documents.

It authenticates with Google OAuth 2.0 using a desktop client owned by the operator. The consent screen you may have seen belongs to this tool.

Google data accessed (read-only)

  • Google Drive — list and download files and folders the authorizing account can already see (drive.readonly)
  • Google Sheets — read spreadsheet values and structure (spreadsheets.readonly)
  • Google Docs — read document text (documents.readonly)
  • Google Slides — read presentation content (presentations.readonly)
  • Google Forms — read form structure and responses (forms.body.readonly, forms.responses.readonly)
  • Gmail — read messages and labels (gmail.readonly)
  • Google Calendar — read events and calendars (calendar.readonly)
  • Google Contacts — read the account's contacts (contacts.readonly)

No write, edit, delete, send, or sharing capability is requested. Every scope is a .readonly scope. The tool cannot modify, send, or share anything in the account.

Who can use it

Only the single operator who owns the OAuth client and who has authorized the tool on their own Google account. There is no sign-up, no multi-tenant service, and no other user data is collected.
