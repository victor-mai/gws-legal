Privacy Policy

GWS Read-Only Automation · Effective 26 October 2026

This policy explains how the GWS Read-Only Automation tool ("the Tool") accesses, uses, stores, and shares information obtained from Google APIs. The Tool is a private, single-operator utility; it is not offered as a public service and has no users other than its operator.

1. Information the Tool accesses

When the operator authorizes the Tool with their own Google Account, the Tool may read:

  • files and folders in Google Drive the account can already access (drive.readonly);
  • Google Sheets values and structure (spreadsheets.readonly);
  • Google Docs text (documents.readonly);
  • Google Slides content (presentations.readonly);
  • Google Forms structure and responses (forms.body.readonly, forms.responses.readonly);
  • Gmail messages and labels (gmail.readonly);
  • Google Calendar events and calendars (calendar.readonly);
  • Google Contacts belonging to the account (contacts.readonly).

The Tool never requests write, send, delete, or sharing scopes.

2. How the information is used

Data is used exclusively to generate internal operational reports for the operator — for example enrolment and attendance summaries, CRM spreadsheets, and training or timetable documents. Data is not used for advertising, profiling, credit assessment, or any purpose unrelated to producing those reports.

3. Storage and security

Data is processed locally on the operator's own computer. Report outputs are stored in local project folders and, where the operator chooses, in the same Google Workspace account that authorized the Tool. The OAuth credential (refresh token) is stored in a local, user-scoped file on the operator's machine, is never committed to a public repository, and is not transmitted to any third party. The Tool is not hosted on a public web server and exposes no API endpoint that serves Google user data.

4. Sharing and disclosure

Google user data is not sold, rented, transferred, or disclosed to third parties, advertising networks, data brokers, or AI model trainers. No human reads the content except the operator. Data may be disclosed only if strictly required by applicable law, and then limited to what is legally required.

5. Limited Use

The Tool's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

6. Retention and deletion

Locally generated report files are retained until the operator deletes them. Revoking the Tool's access at myaccount.google.com/permissions immediately invalidates the stored refresh token and stops all further access. The operator may also delete the local credential file, which removes the only stored authorization artifact.

7. Children's data

The Tool is not directed at children. Where reports contain student records, those records are processed by the operator in their professional capacity under the operator's own institutional data-protection obligations.

8. Changes

Material changes to this policy will be published on this page with a new effective date.
